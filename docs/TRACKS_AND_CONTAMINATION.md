# Tracks and Contamination

## Clean track

A clean version was not designed or executed using gold values, reference answers, organizer-supplied solution workflows, scorer behavior, or task-level feedback that is equivalent to a hidden label from the evaluation set.

Public domain knowledge, published interoperability specifications, general software tools, and participant-designed methods remain permitted.

## Exposed track

A version moves to the exposed track after its design uses task-level gold-like feedback, manual debugging on hidden cases, or equivalent information. The participant may continue improving without limit, but the version cannot be reported as clean on the same evaluation set.

## Assisted track

Human action after an explicit handoff belongs to an assisted continuation. The prior autonomous trajectory remains reportable, but the joint human-system outcome is not autonomous completion.

## Set-specific status

Contamination is version-specific and evaluation-set-specific. A participant may regain a clean claim on a genuinely fresh sealed set if the new version and its development evidence satisfy the clean-track policy.
