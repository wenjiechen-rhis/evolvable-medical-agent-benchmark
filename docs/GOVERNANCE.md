# Governance and Adjudication

Official correctness, real-world task correctness, and governance correctness are separate axes. The public toolkit computes only mechanical aggregates. Claims beyond official labels require independent adjudication under a preregistered rubric.

## Contract disputes

A participant challenge should identify the visible contract clause, event evidence, and claimed discrepancy. The operator responds with the scoring predicate's visible basis while protecting unrelated hidden cases. If no visible basis exists, the item is marked contract-disputed for that benchmark version. A future contract revision cannot retroactively make an undisclosed obligation visible.

## Release changes

A contract change that alters a scored obligation requires a new major protocol or benchmark version. A scorer repair that preserves the visible obligation receives a new evaluator version and operates on the same frozen execution.

## Independent review

Reviewers should assess external evidence rather than architecture names or private reasoning. Disagreement, abstention, and insufficient evidence are valid outcomes. Participant identity should be masked where feasible.

## Task retirement

Leaked or structurally ambiguous cases should be retired rather than silently repaired. Historical reports retain their original status. Fresh replacement sets support later clean evaluation.
