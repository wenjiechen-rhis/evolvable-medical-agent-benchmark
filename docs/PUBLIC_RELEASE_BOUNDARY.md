# Public Release Boundary

The repository contains benchmark infrastructure, not a solution.

## Permitted

- public task- and tool-contract schemas;
- neutral adapter and event formats;
- manifest, validation, hashing, receipt, and report tools;
- non-answer-bearing mechanical conformance fixtures;
- public metric definitions and governance procedures;
- signed aggregate or task-level results released under the declared data policy.

## Prohibited

- gold answers or patient-specific expected values;
- hidden task instances for a sealed track;
- scorer code, scoring predicates, or diagnostic channels that reveal them;
- official solution policies, substantive example agents, or reference workflows;
- any comparator controller code, pseudocode, prompt, rule, module, class name, configuration, internal state name, trace, example submission, or reconstructive mapping;
- fixtures whose expected behavior was copied from a comparator rather than derived from the public contract;
- secrets, credentials, or identifiable data.

The boundary applies to documentation, examples, tests, generated artifacts, release archives, issue attachments, and repository history, not only to source directories.
